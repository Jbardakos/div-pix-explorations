# div-pix-explorations

Browser experiments in pixel aesthetics by Iannis Bardakos. Every file is a single self-contained HTML page: open it in a browser and it runs. No server, no build step, no dependencies.

Start with [`preview.html`](preview.html), a visual index of the experiments.

## Families

| Prefix | Theme |
|---|---|
| `perlin_*` | Perlin-noise driven grids, ASCII fields, datamosh pixels, particle dithers |
| `zk_*` | Synth-like compositors and degenerative live pieces |
| `tf_*` | Wave interference, glitch, cellular automata destruction |
| `living_*`, `datamosh*` | Smears and datamosh loops on small grids |
| `3x3_grey_walkers*`, `grey_mosaic`, `dither_grid`, `eye_div_grid` | Grey-scale walkers, mosaics and dithers built from DIV grids |

Files ending in `_v1` / `_v2` are earlier or later iterations of the same experiment, kept on purpose.

`zk_preset.txt` holds presets for the `zk_synth` pieces.
